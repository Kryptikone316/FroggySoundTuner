# Changelog

## 1.0

- Presets (five ready-made, your own with names), a 10-band Equalizer with live changes, a Speaker
  Fix tab and an About guide.
- The equalizer setting stays on while other programs run and is cleared at power-off; the app remembers
  which preset it left on for the rest of the boot.
- Eleven languages through TreeFrogUI's language setting (ten drafts awaiting review), with a name
  entry grid for each language's letters.
- The layout follows the panel's shape (640x360 on the SF3500's 854x480 panel).
